# 零偽造與零竄改實測物理量鐵律 (Zero-Fallback & Zero-Tampering Telemetry Integrity Rule)

## 1. 核心物理原則與禁止清單 (Strictly Forbidden)
* **嚴禁「幽靈數值偽造」**：
  * **嚴禁**在任何即時控制、保護、看門狗（Watchdog）或演算法中，將「實測為 0 的物理量」（如轉速 $0\text{ rpm}$、電流 $0\text{ A}$、電壓 $0\text{ V}$、轉矩 $0\text{ Nm}$）強制以「額定值」、「銘牌值」（如 `lastB_Dr01`, `lastB_Dr00`）或「歷史最後非零值」覆蓋替換！
* **物理狀態與通訊狀態嚴格脫鉤**：
  * 「數值為 0」是馬達控制與測試中的**正常且關鍵的物理狀態**（如堵轉測試轉速必為 0、斷電或初建壓電流必為 0）。
  * 若通訊中斷或封包遺失，只能標記 `IsConnected = false`、`IsDataTimeout = true` 或丟出通訊超時異常，**絕對嚴禁偽造假數據填補**。
* **嚴禁一般運轉與極端測試共用保護校驗**：
  * 堵轉測試、空載測試、耐壓測試等特殊工況，其電壓、頻率、轉速與電流特徵與一般負載運轉截然不同。
  * 嚴禁用一般額定電壓（如 220V/260V）或一般運轉速度門檻去限制或攔截堵轉測試（如 10V、0 rpm）。

## 2. 審查與自檢要求 (Self-Audit Pipeline)
1. **接觸前清查**：凡修改控制迴路與看門狗，必須主動搜尋是否存在 `spdCur <= 0.5`、`iCur <= 0.05` 等偽造替換語句。
2. **違規即擋**：若在控制代碼中發現任何以額定參數覆蓋即時遙測之邏輯，視同重大系統缺陷，必須立即予以根除。
