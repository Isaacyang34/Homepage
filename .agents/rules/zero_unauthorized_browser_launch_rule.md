# 嚴禁未經指示擅自開啟瀏覽器鐵律 (Zero Unauthorized Browser Launch Rule)

## 1. 核心宗旨
本工作區所有專案（含 Web 應用、HMI、演算法工具與腳本）在執行任何開發、除錯、重構與驗證時，**絕對嚴禁未經使用者明確指示擅自調用瀏覽器工具或開啟任何本地瀏覽器視窗**。

## 2. 強制禁令
- **禁止未經授權調用 `browser_subagent`**：除非使用者在 Prompt 中明確指明「請打開瀏覽器測試」、「啟動瀏覽器檢視」等字眼，否則嚴禁將瀏覽器測試作為自動驗證的一環。
- **禁止系統指令喚醒瀏覽器**：嚴禁在 PowerShell 或命令列執行 `Start-Process chrome`, `start msedge`, `start http://...` 或任何喚醒 GUI 瀏覽器之行為。
- **禁止奪取作業系統焦點**：任何跳出視窗（Pop-up）、分頁切換都會中斷使用者當下的工作與打字流程，屬於致命的使用者體驗破壞。

## 3. 離線與背景驗證替代準則
- **靜態語法與 DOM 檢查**：透過 Node.js、PowerShell 或 Python 腳本於背景對 HTML/JS 進行 AST 分析、正則比對或無頭解析。
- **演算法與資料解析驗證**：撰寫背景測試腳本讀取真實二進位檔或數據流，於終端機輸出斷言結果。
- **回報即止**：代碼撰寫與背景測試完成後，直接在回覆中提供修改點說明、實測數據佐證與本地檔案連結（`file:///...`），交由使用者於適合時機自行點擊查看。
