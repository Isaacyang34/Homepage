## 🎨 專屬羽球視覺風格 (Badminton Theme)

1. **專業羽球地膠場地 (Badminton Court Mat)**：
   * 採用國際賽事級深綠地膠質感 (`#0d633d`)，中央設有白色擬真球網隔線 (`.badminton-net`) 與雙打邊界標線。
   * 比賽激戰狀態中，場地啟動動態呼吸邊框 (`.court-fighting`) 與「🔥 激戰中」標章。
2. **球員球衣卡片設計 (Player Jersey Cards)**：
   * 藍色球衣 (男單/男雙)、粉紅球衣 (女單/女雙)、薄荷綠 (不拘)。
   * 強度等級以立體徽章呈現 (`🏸 高階`、`🏸 中階`、`🏸 初階`、`🏸 新手`)。
   * 本人卡片專屬金綠漸層「我的」標章；冷卻中球員顯示動態計時器 (`⏱ 04:32 休息中`)。
3. **休息備戰區 (Players Dugout / Benches)**：
   * 沉浸式場邊候命區，清晰呈現閒置球員卡片，並提供一機一卡報名確認面板。

## 🛡️ 實戰核心防呆與強固機制

1. **📱 取回碼 (手機末 3 碼) 卡片認領 (必填)**：
   * 球員加入球局時，取回碼強制必填 3~6 碼純數字（自動切換手機數字鍵盤）。
   * 資料庫只存 64-bit 雙重雜湊值，兼顧現場隱私。
   * 跳出 LINE 或更換手機時，頂部主動亮起引導條，輸入末 3 碼立即秒「認領名子」！
   * 支援「連同攜伴一併轉移」核取方塊，免去重複認領。
2. **🚫 全場防重名機制 (Anti-Duplicate Name)**：
   * 跨全場（打球中、排隊區、自由區）不分大小寫比對，嚴格禁止同名卡片，杜絕場上辨識混淆。
3. **👥 一機一卡限制 (防洗版/防多佔位)**：
   * 預設每台手機限登記 1 位成員。球員登記完成後，表單自動切換為確認卡，防止一人連按多卡。
   * 主辦人可在「⚙️ 設定」彈性調整「每位球友登記名額 (1人 / 2人 / 3人 / 不限)」。
4. **👑 主管理員 6 碼救援碼 (Admin Recovery Key)**：
   * 建房時自動生成 6 碼救援碼，主辦人跳出 LINE 失去皇冠時，輸入救援碼即可瞬間奪回最高管理權限。
5. **🛠️ 主辦人現場人工救援 (Admin Re-assign & Reset)**：
   * 長輩或球友忘記取回碼時，主辦人打開卡片即可「一鍵綁定給我」或「幫球員重設手機末 3 碼」。
6. **⚠️ 離線連線即時感知 (`.info/connected`)**：
   * 球館訊號斷線時，頂部亮起醒目紅色警示條，避免使用者盲目狂按造成資料覆寫。

## 🚀 本地啟動方式

直接在檔案總管中雙擊：
```text
run_local.bat
```
或在終端機中執行：
```powershell
cd WEB_ShuttleFlow_Badminton_Queue
python serve.py
```
系統會自動在預設瀏覽器開啟 `http://localhost:8088/` 進入全新「羽樂排 (ShuttleJoy) v1.0」大廳！
