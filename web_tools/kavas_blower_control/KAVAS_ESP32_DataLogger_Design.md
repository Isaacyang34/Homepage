# KAVAS 鼓風機 ESP32 Wi-Fi 雲端上傳資料記錄器設計報告

本報告針對 **克瑪里能源科技 (GPE) KAVAS MTB-5HP 鼓風機**，設計基於 **ESP32 Wi-Fi 雲端上傳** 之 3 通道 Modbus RTU 資料記錄器。系統採用 **NTP 網路自動校時**、**DHT22 工規環境溫濕度監控**、**8dBi 外接高增益延長天線** 與 **動態採樣 / LittleFS 斷線快取補傳機制**。

## 📡 二、 動態採樣週期與外接天線硬體配置

### 1. 動態採樣與上傳策略 (Dynamic Polling Rate)
- **Wi-Fi 連線正常時**：**每 5 秒採樣並上傳 1 次** (高頻實時動態監控)。
- **Wi-Fi 斷線/障礙時**：自動切換為 **每 1 分鐘採樣 1 次** 並快取寫入 ESP32 內部 Flash (極致節省暫存空間)。
- **故障事件 (Fault Event)**：不論連線或斷線，一旦檢測到鼓風機出現故障碼變更，**發送/快取紀錄 + 即時 LINE 通知**。
- **網路恢復自動補傳**：Wi-Fi 重連後，自動將斷線期間以 1 分鐘間隔紀錄的歷史 Log 批次補發至雲端，成功後自動清空 Flash 暫存。

### 2. 外接天線硬體配置
現場工業環境金屬箱體與屏蔽易造成 Wi-Fi 訊號衰減，硬體配置說明如下：

```text
  ┌──────────────────────────────────────────────────────────┐
  │  IP65 防水防塵控制箱                                      │
  │                                                          │
  │   ┌─────────────────────┐                                │
  │   │ ESP32-WROOM-32U     │                                │
  │   │  [IPEX/U.FL 座] ────┼──┐ (IPEX 轉 SMA RG178 延長線 1.5M)
  │   └──────────┬──────────┘  │                             │
  │              │ (GPIO 14)   │                             │
  │   ┌──────────┴──────────┐  │                             │
  │   │ DHT22 溫濕度感測器  │  │                             │
  │   │ (監控機房環境溫濕度)│  │                             │
  │   └─────────────────────┘  │                             │
  └────────────────────────────┼─────────────────────────────┘
                               │ (穿出控制箱外壁)
                               ▼
                    ┌──────────────────────┐
                    │ 8dBi 2.4GHz 全向高增 │ (固定於箱體頂部高處
                    │ 益天線 (SMA 公頭)    │  遠離金屬遮蔽物)
                    └──────────────────────┘
```

1. **主控板選擇**：採用 **ESP32-WROOM-32U**（**自帶 IPEX / U.FL 微型天線座**）。
2. **天線延伸**：使用 **IPEX 轉 SMA 母頭 1.5M 高頻轉接線 (RG178 / RG316)**，將 SMA 連接埠穿出金屬外殼。
3. **天線本體**：搭配 **8dBi 2.4GHz 高增益 SMA 全向天線**，增益可提升 8~12 dB。
4. **環境溫濕度**：加裝 **DHT22 / AM2302 工規溫濕度感測器** (連接 GPIO 14)，即時監測風機安裝環境之溫度與相對濕度。

## 💾 三、 斷線暫存機制與 LittleFS 快取容量極致評估

當現場 Wi-Fi 斷線時，系統自動調整為 **每 1 分鐘紀錄 1 次** 寫入 LittleFS。以下為不同 Flash 配置下能保存的斷線時間計算：

| ESP32 Flash 總容量 | LittleFS 可用暫存分區 | 可保存記錄總筆數 | **斷線持續保存時間估算** |
| :---: | :---: | :---: | :---: |
| **4MB Flash** *(標準版)* | **1.5 MB** (1,572,864 B) | 約 **22,400 筆** | **約 5.2 天 (124 小時)** |
| **8MB Flash** | **4.5 MB** (4,718,592 B) | 約 **67,400 筆** | **約 15.6 天 (374 小時)** |
| **16MB Flash** *(推薦升級)* | **12.5 MB** (13,107,200 B)| 約 **187,200 筆** | **約 43.3 天 (1,040 小時 / 1.4個月)** |
