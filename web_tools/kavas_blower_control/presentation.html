頻率轉速物理公式

極數 $p = 2$ (4 極馬達)，同步轉速公式：

N = (120 × f) / 4 = 30 × f

運轉頻率在 $0 \sim 800.0\text{ Hz}$ 之間精準對應 $0 \sim 24,000\text{ RPM}$。

基頻與弱磁雙區物理特性

  • 基頻常轉矩區 ($0 \sim 5,000\text{ RPM}$)：頻率 $0 \sim 166.7\text{ Hz}$，電壓隨頻率正比上升至 $380\text{ V}$ ($V/f$ 定值)。
  • 弱磁高速區 ($5,000 \sim 24,000\text{ RPM}$)：頻率 $166.7 \sim 800.0\text{ Hz}$，電壓飽和封頂於 $380\text{ V}$，磁通隨頻率增加而衰減。

LINE 秒級告警機制

ESP32 每秒上傳轉速、頻率、電壓、電流與故障碼，當 `fault_code != 0` 時，Google Apps Script 自動秒發 LINE Notify 推送告警訊息給工程團隊。

GBD 樣式 X 軸全量滾輪檢視

整合 `chartjs-plugin-zoom`，滾輪向後拉遠可完整瀏覽從 10:38 開始迄今的所有時間點；Y 軸由系統根據數據動態 Auto-Scale 最佳範圍。
