  馬達綜合動力計測試系統 (Dynamometer HMI Pro V2.2.0) - 操作使用說明書

一、 系統簡介
--------------------------------------------------------------------------------
本軟體為專用於工業馬達／主軸動力特性、閉迴路安全防護、T-N 曲線、2D 效率地圖
以及 IEC 60034-1 標準 S1/S2/S6 工作制測試之現代化上位機監控系統。
原生支援 Windows 10 / 11 (64-bit)，完全免安裝、免註冊任何舊版元件，隨插即用。


二、 快速啟動
--------------------------------------------------------------------------------
1. 直接在資料夾中雙擊執行：【Start_Dynamometer_HMI.bat】
2. 系統將自動於預設瀏覽器 (Edge / Chrome) 開啟現代化暗色系監控操作面板。
3. 若現場無實體硬體，可勾選畫面上的「模擬測試 (Simulation)」進行流程演練。


三、 獨立設備通訊測試 (tools\ 資料夾)
--------------------------------------------------------------------------------
在進行正式測試前，建議先至 tools\ 資料夾個別驗證設備連線：

1. 🔧 USB 專用扭力計測試：
   - 雙擊執行：tools\Test_USB_TorqueMeter.exe
   - 程式會自動列出偵測到的 COM 埠，輸入 COM 埠（如 COM3）與鮑率（預設 9600）。
   - 系統將每 200ms 發送 4503A 指令 (MEAS:TORQ?) 並即時顯示實測轉矩 (Nm)。

2. 🌐 功率分析儀 (Power Meter) 網路測試：
   - 雙擊執行：tools\Test_PowerMeter_Ethernet.exe
   - 輸入儀表 IP（如 192.168.1.100）與 Port（Yokogawa 預設 10001）。
   - 系統將自動讀取三相電壓、電流、總功率 (kW) 與功率因數。

3. 📡 GBD 網路多通道溫度記錄器 (Graphtec GL 系列) 測試：
   - 雙擊執行：tools\Test_Graphtec_GBD_Ethernet.exe
   - 輸入 GBD 記錄器 IP（預設 192.168.1.101）與 Port（預設 8023）。
   - 系統將發送 :MEAS:ALL? 讀取並顯示 CH1~CH20 完整多測點溫度數據。

4. ⚙️ KEB 驅動器測試：
   - 執行命令：python tools\test_keb_drive.py -p COM1 -b 9600 -a 1
   - 讀取 ru01 (設定轉速)、ru07 (實際轉速)、ru15 (電流)、ru18 (DC Bus 電壓)、Sy51。


四、 四大核心測試功能操作說明
--------------------------------------------------------------------------------

【分頁 1：🎛️ 手動即時監控 & 閉迴路安全防護】
1. 轉速與加載控制：透過介面滑桿或輸入框設定目標轉速 (rpm) 與加載轉矩 (Nm)。
2. 閉迴路防暴衝安全防護：
   - 當馬達運轉穩定時，點擊「📸 確認並記錄基準」，鎖定當前正常轉矩值。
   - 若後續感測器訊號跳變或異常超過 10%（門檻可自訂），頂部立即觸發紅燈與警示橫幅。
   - 系統自動啟用輸出限幅器 (Rate Limiter)，單步調整量嚴格限制（如 ±2.0 Nm 以內），
     防止任何控制爆衝。
3. 點擊「📥 匯出即時 CSV 報表」即可下載 100% 相容舊版欄位之測試報表。

【分頁 2：📈 多段 T-N 曲線自動測試】
1. 設定起始轉速（如 100 rpm）、步階（如 100 rpm）、結束轉速（如 1000 rpm）。
2. 設定固定加載轉矩（如 30.0 Nm）與每點穩定等待時間（如 10 秒）。
3. 點擊「🚀 開始多段 T-N 自動測試」，系統將自動逐段升速、穩定倒數計時、記錄數據。
4. 測試完成後自動繪製「實測功率 kW 與系統效率 % 曲線」，並可匯出專屬 T-N 報表。

【分頁 3：🗺️ 2D 效率地圖自動掃描】
1. 設定轉速範圍（100~1000 rpm，間隔 100 rpm）與轉矩範圍（0~30 Nm，間隔 2 Nm）。
2. 系統自動計算網格點數（10 × 16 = 160 點），設定每點穩定時間（如 3 秒）。
3. 點擊「🗺️ 開始掃描 2D 效率地圖」，系統將自動全工況巡航掃描。
4. 畫面上即時繪製 2D 效率熱力圖（<70% 藍色 → 80% 青色 → 90%+ 綠色高效區）。
5. 點擊「📥 匯出效率地圖矩陣 CSV」可匯出完整 2D 矩陣數據。

【分頁 4：⏱️ S1 / S2 / S6 標準馬達工作制測試 (IEC 60034-1)】
1. S1 連續運轉工作制：
   - 設定額定轉速與轉矩，連續運轉。
   - 內建「熱平衡自動判定」：當連續溫升變動率 ΔT < 0.2°C 時自動標示並完成測試。
2. S2 短時運轉工作制：
   - 設定短時超載轉矩（如 45 Nm）與短時時間（10/15/30/60 分鐘）。
   - 時間到達後自動卸載，進入冷卻階段記錄。
3. S6 連續週期運轉工作制：
   - 選擇負載持續率 ED%（S6-25%, S6-40%, S6-60%）與單週期時長（如 60s 或 600s）。
   - 系統自動在「🔴 加載運轉期」與「🟢 空載運轉期」之間自動切換並進行多週期循環。
4. 提供雙軸波形歷程圖與溫升曲線圖，並可匯出專屬工作制 CSV 報表。


五、 跨電腦更換與攜帶說明
--------------------------------------------------------------------------------
1. 本發布資料夾為完全獨立的「綠色便攜版 (Portable)」。
2. 您只需將此資料夾複製到隨身碟，插到任何一台 Windows 10 / Windows 11 電腦，
   不需要安裝 Python 或註冊任何 OCX，雙擊 Start_Dynamometer_HMI.bat 即可立即使用！
