## 📝 詳細改版履歷 (Detailed Changelog)

### [v2.4.0] - 2026-08-25
#### 🌟 核心更新 (Key Improvements)
- **介面純淨化與命名重構**：
  - 程式視窗標題純化為 **`Dynamometer HMI`**（移除中文）。
  - 主控台標題橫幅更新為 **`⚡ 馬達動力計測試平台`**。
  - 全面移除「雙軌KEB」字眼，統一將 1號/2號 重新命名為 **「A載台」**（主動端）與 **「B載台」**（負載端）。
- **一迴路主捲平滑追隨與軟體模擬獨立彈窗 (`⚙️ 追隨/模擬`)**：
  - 將原面板固定控制項移入獨立對話框 (`ClosedLoopControlDialog`)，保留基準轉矩鎖定、滑動平均窗口平滑濾波 (Moving Average Filtering)、變化死區與偏差安全門檻設定，並整合軟體示範模擬模式開關。
- **馬達溫度專區與 1 秒 (1Sec) 即時動態趨勢圖**：
  - 於原閉迴路空間設立「馬達溫度」監控卡，將通道選單寬度減半精簡佈局。
  - 搭載高解析每秒動態波形圖 (`MotorTempTrendControl`)，支援 0~120°C 曲線漸層填色與最新取樣標示。
- **頂部 6 大核心卡片加入「輸入功率」**：
  - 卡片順序重新排列為：**實測轉速** ➔ **實測轉矩** ➔ **機械功率** ➔ **輸入功率 (kW)** (WT333E 即時遙測) ➔ **系統效率** ➔ **扭力常數**。

### [v2.3.0] - 2026-08-25
#### 🌟 新增功能 (Added)
- **雙軌 KEB 變頻驅動器完整控制面板 (Drive 1 COM1 驅動端 + Drive 2 COM2 負載動力計)**：
  - **4 大運轉模式切換按鈕**：
    - 🟢 **數位定轉速 (Digital Speed)**：自動配置 `oP00=2, oP01=8, cs00=4, cs15=3`
    - 🔵 **數位定轉矩 (Digital Torque)**：自動配置 `oP00=2, oP01=8, cs00=6, cs15=3`
    - 🟡 **類比轉速模式 (Analog Speed 0~10V)**：配置 `oP00=0, oP01=7, cs00=4, cs15=2`
    - 🟣 **類比轉矩模式 (Analog Torque 0~10V)**：配置 `oP00=0, oP01=7, cs00=6, cs15=1`
  - **轉速與轉矩步階微調列**：
    - 轉速微調：`[-100]`, `[-1]`, `[數值框]`, `[+1]`, `[+100]` RPM 快速按鈕 + `[ 🚀 寫入速度 (oP03) ]`
    - 轉矩微調：`[-1%]`, `[-0.1%]`, `[數值框]`, `[+0.1%]`, `[+1%]` % 快速按鈕 + `[ 🎯 寫入轉矩 (cs18) ]`
  - **即時運轉控制**：
    - `[ ▶ 正轉 (FOR) ]` (Sy50=1)、`[ ◀ 反轉 (REV) ]` (Sy50=2)、`[ 🛑 停機 (STOP) ]` (Sy50=0)、`[ ⚡ 故障復歸 ]` (Sy50=4)
- **完整 `ru` 群組即時量測監視儀表板 (Read Units Telemetry)**：
  - `ru00`：變頻器狀態字元 (Ready / 運轉 / 停機)
  - `ru01`：實際轉速回授 (RPM)
  - `ru26`：實際輸出轉矩 (Nm)
  - `ru07`：變頻器輸出電流 (A)
  - `ru09`：變頻器輸出電壓 (V)
  - `ru10`：直流母線電壓 (VDC)
  - `ru11`：即時有效功率 (kW)
  - `ru20`：馬達內部溫度 (°C)
  - `ru43`：故障代碼 (Fault Code)
- **Windows Smart App Control 信任憑證與 Manifest 相容性補強**：
  - 加入標準 `app.manifest`（`asInvoker`）與 C# Assembly 元數據，徹底解決 Windows 11 Smart App Control 警示。
- **Yokogawa WT333E 與 Graphtec GL820 解碼優化**：
  - WT333E Modbus FC04 補齊 2-byte 狀態字元位移（Float Offset = 11），未上電讀值精確歸零。
  - GL820 自動通道鎖定，過濾未接線的 3276.5°C 雜訊。

### [v2.2.0] - 2026-08-24
#### 🌟 新增功能 (Added)
- **S1/S2/S6 工作制測試模組 (IEC 60034-1 Standard)**：
  - **S1 (連續運轉)**：恆定額定加載，自動溫升斜率監控與「熱平衡自動判定」完成測試。
  - **S2 (短時運轉)**：10/15/30/60 分鐘短時超載運轉與冷卻追蹤。
  - **S6 (連續週期運轉)**：負載率 ED%（25%、40%、60%）自動雙階段切換與多週期循環。
- **GBD 網路多通道溫度記錄器支援 (Graphtec GL 系列)**：
  - 透過 TCP Port 8023 即時採樣 CH1~CH20 溫度。
