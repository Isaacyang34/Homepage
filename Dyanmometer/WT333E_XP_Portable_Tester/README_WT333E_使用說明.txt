================================================================================
  橫河 YOKOGAWA WT333E 數位功率計 Modbus TCP 通訊測試工具 - 使用說明書
================================================================================

【軟體版本】：V1.0.0 Portable (相容 Windows XP / 7 / 10 / 11)
【適用設備】：YOKOGAWA WT333E / WT310E / WT300E 系列 (搭載 /C7 乙太網路卡)
【預設設定】：IP: 192.168.0.11 | Port: 502 (Modbus TCP) | 站號 ID: 1 | 功能碼: FC 04

--------------------------------------------------------------------------------
一、快速開始 (3 秒啟動)
--------------------------------------------------------------------------------
1. 請確認電腦與 WT333E 在同一區域網路（或直連），電表 IP 設定為 192.168.0.11。
2. 直接雙擊執行【啟動WT333E測試.vbs】或【WT333E_Tester_GUI.exe】。
3. 介面開啟後：
   - 點擊【⚡ 單次查詢 (Single Read)】：立即發送一次 Modbus TCP 請求並解析三相數值。
   - 點擊【▶ 開始連續讀取 (Poll)】：以 500ms 週期連續輪詢，表格與日誌即時刷新。

--------------------------------------------------------------------------------
二、三相與 SIGMA 物理量對齊說明
--------------------------------------------------------------------------------
軟體可同時解碼三相與總和數值，並呈現於專屬量測矩陣：
1. 電壓 U (Voltage)       : U1 (L1), U2 (L2), U3 (L3), USig (總和/平均電壓) [單位: V]
2. 電流 I (Current)       : I1 (L1), I2 (L2), I3 (L3), ISig (總電流)        [單位: A]
3. 有功功率 P (Active Power): P1, P2, P3, PSig (總有功功率)                  [單位: kW]
4. 視在功率 S (Apparent)  : S1, S2, S3, SSig (總視在功率)                  [單位: kVA]
5. 無功功率 Q (Reactive)  : Q1, Q2, Q3, QSig (總無功功率)                  [單位: kvar]
6. 功率因數 PF (λ)        : PF1, PF2, PF3, PFSig (總功因)                   [-1.0 ~ 1.0]
7. 相位角 Φ (Phase Angle) : Φ1, Φ2, Φ3, ΦSig                                [單位: °]
8. 頻率 Freq (Frequency)  : 60.00 Hz / 50.00 Hz                             [單位: Hz]

--------------------------------------------------------------------------------
三、診斷與輔助排查工具
--------------------------------------------------------------------------------
1.【🔍 128 暫存器全矩陣 Dump】：
   - 自動傾印 0x0064 (100)、0x0100 (256)、0x0150 (336)、0x0000 區塊之所有 IEEE-754 浮點數。
   - 自動高亮標記電壓 (~52V)、電流 (~15A)、總電流 (~30A)，一鍵定位暫存器實體位址。

2.【🎯 智能特徵求解 (Auto-Solve)】：
   - 自動對不同區塊與跨距進行三相電流平衡、電壓平衡與功率閉環驗算，自動鎖定最準確之解碼配置。

3.【浮點數字節順序切換】：
   - 支援 Big-Endian (ABCD - 橫河標準)、Word-Swap (CDAB)、Byte-Swap (BADC)、Little-Endian (DCBA)。

--------------------------------------------------------------------------------
四、自動日誌與 CSV 遙測
--------------------------------------------------------------------------------
- 所有通訊電文 (HEX 原始封包) 與異常均自動記錄至 `logs/wt333e_tester_<時間>.log`。
- 每秒產生標準遙測記錄至 `logs/Auto_Raw_Telemetry_WT333E_<時間>.csv`，便於使用 Excel 或 Python 進行動力學與電氣分析。
- 點擊【📁 開啟日誌目錄】即可直接瀏覽日誌檔案。
