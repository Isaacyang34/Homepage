# 電動車進料檢驗自動分類與自主學習系統 (EV Inspection Auto Classifier)

> **版本**：V1.2 (原生獨立執行檔版 | 嚴格可靠度門檻與主動學習回饋)  
> **特性**：
> - **可靠度 >= 95.0% 嚴格門檻**：辨識信心度達標才自動採納；凡有疑義或低於 95% 者，強制隔離列入專屬審核清單。
> - **人工審核判定與主動學習 (Active Learning)**：透過人工判定視窗快速校正料號與數量，系統自動儲存至知識庫 (`learning_rules.json`)，日後同類單據 100% 自動採納！
> - **直接點擊執行檔 (`.exe`)**：無需安裝 Python，雙擊即用。
> - **100% 地端離線運行、零 Token 消耗 (0-Token)**。
> - **內建深層除錯診斷 (Debug Diagnostic)**：即時排查非標準單據、未匹配 BOM、手寫件或樣品。
> - **三標籤互動式介面**：【全部單據清單】、【待人工判定審核區 (<95%)】與【自主學習規則庫管理】。
> - **原廠 BOM 規格自動比對**：自動計算整車折合套數與組裝齊套分析。
> - **三合一格式化 Excel 總表輸出**：包含月度統計、逐筆明細、齊套率色階分析。

## 二、 可靠度評估 (Reliability Score) 與人工判定學習機制

本系統導入了嚴格的品質把關架構：

### 1. 四維評分權重體系 (滿分 100%)
- **BOM 標準料號匹配 (35%)**：精確吻合原廠 BOM 需求表者得 35 分，未匹配扣 30 分。
- **工單與日期標準格式 (25%)**：檔名具備完整日期與工單批號者得 25 分，缺工單扣 15 分。
- **進貨數量有效驗證 (25%)**：成功辨識並核對有效進貨數量 (>0 PC) 得 25 分，未檢出者為 0 分。
- **單據健康特徵 (15%)**：標準檢驗單據得 15 分；若含 NG、草稿、筆記則進行負分修正。

### 2. 嚴格門檻判定邏輯
- **可靠度 $\ge 95.0\%$**：標記為「自動採納」，直接通過。
- **可靠度 $< 95.0\%$**：標記為「待人工判定」，**強制隔離**並自動切換至【待人工判定審核區 (<95%)】。

### 3. 人工審核判定與自主學習閉環 (Feedback Learning Loop)
1. **觸發方式**：在【待人工判定審核區】選取單據後點擊【[!] 進行人工審核判定與學習】（或直接雙擊該列）。
2. **審核視窗**：
   - 顯示原檔特徵、扣分原因與當前評分。
   - 提供標準 BOM 下拉選單快速指定正確料號。
   - 輸入正確進貨數量、工單與檢驗備註。
   - 勾選 `[v] 立即寫入自主學習庫`。
3. **學習反饋效果**：
   - 單據可靠度立即提升至 **100.0%**，狀態轉為「人工已核定」，自動自待判定清單中移除。
   - 系統自動將別名映射 (Alias Mapping) 與工單數量記憶寫入 `learning_rules.json`。
   - **永久累積**：日後再次掃描或遇到同類特徵單據，系統自動以 100% 可靠度直接採納，徹底免除重覆審核！

## 三、 標準使用步驟

1. **選擇待分類資料夾**：
   - 點擊「瀏覽...」選取待處理之進料檢資料夾（預設為 `資料搜尋/2026電動車進料檢記錄`）。
2. **第一步：點擊【1. 掃描與解析 PDF】**：
   - 系統秒級完成所有 PDF 之特徵提取與可靠度評分。
3. **第二步：人工審核判定 (若有 <95% 單據)**：
   - 系統若發現未達標單據，會自動切換至【待人工判定審核區 (<95%)】。
   - 點擊【[!] 進行人工審核判定與學習】進行快速校正與存入學習庫。
4. **第三步：點擊【2. 一鍵執行分類與產出報表】**：
   - 系統自動執行分類歸檔、建立各資料夾之統計 TXT、產出格式化 Excel 與 CSV 總表。
5. **檢視結果**：
   - 點擊【開啟目標目錄】或【開啟統計 Excel】直接檢視成果！
