# 本地端台美股庫存即時損益與歷史追蹤系統 (Stock Portfolio Tracker)

專為注重個人資產隱私、需要精確損益計算與歷史 K 線盤後追蹤所打造的 **100% 本地端桌面工具**。所有的庫存帳本與歷史資料皆儲存在本機 SQLite 資料庫中，**絕不上雲**。

---

## 核心亮點與防爬蟲阻擋機制

### 1. 為何不會被證交所或各大網站封鎖 (Ban IP / 403)？
- **TWSE MIS 官方官方批次端點**：採用台灣證券交易所對外公開之看盤端點，將你持有的所有股票**一次打包合併查詢**（例：`tse_2330.tw|otc_6547.tw|tse_0050.tw`），一次請求完成全部報價，完全模擬真實看盤軟體。
- **智慧請求限速 (Throttle)**：內建 4 秒最低間隔保護與 Session Cookie 維護，絕不高頻暴衝，保證永不被防護牆誤判為惡意爬蟲。
- **雙軌備援機制**：盤後或離峰若證交所維護，自動無縫切換 `yfinance` 備援。

### 2. 盤後歷史資料「增量更新」技術
- 每天收盤後（13:30 後）點擊 `[盤後] 更新歷史資料庫`。
- 系統會自動比對本地 SQLite 中每檔股票記錄的「最晚日期」，**只向伺服器下載缺漏的最新幾天資料**，而不是每次重抓整年，極省流量、秒級完成，同時將網路請求次數壓至最低。

### 3. 精確台股交易成本計算
- **買進成本**：`買入價格 × 股數 + 買進手續費 (0.1425% × 折扣，低消 20 元)`
- **預估淨賣出**：`現價 × 股數 - 賣出手續費 - 證券交易稅`
  - 一般股票：證交稅 `0.3%`
  - ETF 標的：享有優惠證交稅 `0.1%`（新增持股時勾選 ETF 即自動套用）
- **即時總覽**：隨時掌握未實現損益、淨報酬率 %、單日浮動損益。

## 專案目錄結構

```
TOOL_Stock_Portfolio_Tracker/
├── portfolio.db          # 本地 SQLite 資料庫 (持股、歷史K線、系統設定，自動生成)
├── database.py           # 資料庫存取層 (CRUD、增量寫入)
├── quote_service.py      # 即時報價引擎 (TWSE MIS 批次 + yfinance 備援)
├── history_service.py    # 歷史日 K 線增量下載與盤後更新
├── pnl_calculator.py     # 台美股交易手續費與未實現損益精算
├── main_gui.py           # 現代深色質感 Tkinter 桌面介面
├── main.py               # 程式進入點
├── requirements.txt      # Python 相依套件
├── run.bat               # 雙擊一鍵啟動腳本 (純 ASCII)
└── README.md             # 說明文件
```

## 快速啟動 (多種啟動方式)

- **方式 1 (最推薦 - 獨立便攜執行檔，免安裝 Python)**：
  - 直接雙擊 **`Stock_Portfolio_Tracker.exe`**！
  - 封裝為單一可執行檔，完全零黑框，隨身碟一插即用。
  - 自動於同目錄讀寫 `portfolio.db`，所有持股與歷史資料安全保存在本地。
- **方式 2 (純腳本無黑框模式)**：
  - 雙擊 **`start.vbs`**（利用 Windows Script Host 0 視窗模式啟動 Python）。
- **方式 3**：雙擊 **`run.bat`**。
