# 🎮 遊戲按鍵定義對照規範 (Controls Config & Specification)

本文件明確規範《修仙傳 · MyPixelGame》的所有鍵盤操作熱鍵，確保無任何鍵位重疊與功能衝突。

---

## 📌 一、 核心對照表 (Keybindings Specification)

| 功能類別 | 快捷鍵 (Key) | 功能描述 | 衝突排除說明 |
| :--- | :--- | :--- | :--- |
| **NPC 互動** | `F` | 靠近 NPC 對話 / 推進對話 | **`F` 鍵獨佔**，已完全從煉器功能中移除，防止對話時誤開視窗 |

## 🛠 二、 特殊邏輯機制 (Special Interaction Rules)

1. **`F` 鍵獨佔原則**：
   - 當玩家距離 NPC 75px 內時，畫面出現 `▶ 按 [F] 鍵對話`。
   - 按下 `F` 鍵開啟對話框，再次按下 `F` 鍵推進對話內容。
   - `F` 鍵不觸發任何 UI 視窗彈窗（如煉器坊）。

2. **`ESC` 鍵全閉原則**：
   - 按下 `ESC` 鍵調用全域 `closeAllModals()` 函數，無條件關閉當前所有打開的 Overlay（含背包、地圖、人物、集市、煉丹、煉器、說明等）。
