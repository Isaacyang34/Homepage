# 📦 貨物動態即時追蹤與通知系統 (WEB_Package_Tracker)

[![Tech: Node.js](https://img.shields.io/badge/Backend-Node.js-green.svg)](#)
[![Frontend: HTML5/CSS3](https://img.shields.io/badge/Frontend-HTML5%2FCSS3-blue.svg)](#)

這是一套跨平台貨物包裹即時動態追蹤與瀏覽器桌面推播通知系統。

## 🌟 功能特色
* **多物流平台即時爬取**：自動解析包裹運送狀態、清關進度與派送節點。
* **桌面推播通知 (Web Push Notification)**：包裹狀態變更時自動觸發桌面彈跳視窗警報。
* **歷史追蹤清單**：本地儲存多筆包裹單號與自訂備註名稱。
