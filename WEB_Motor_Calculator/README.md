# ⚙️ 馬達工程與等效電路計算工具箱 (WEB_Motor_Calculator)

提供馬達工程師與電機研發人員在線快速計算馬達參數之純 Web 工具集（支援離線直接開啟）。

## 🛠️ 包含工具
1. **`MotorEquivalentCircuit.html`** / **`等效電路計算.html`**：
   - 感應馬達單相/三相等效電路參數解算 (R1, X1, R2, X2, Xm, Rc)。
   - 繪製轉矩與轉速 (TN/PN) 特性曲線圖。
2. **`MotorCalculate.html`**：
   - 額定功率、極數、轉差率 (Slip)、同步轉速與效率試算。
