# ETF 即時金融數據對接規格與客觀計算公式說明

本系統全面廢除人工寫死常數，所有標的資訊均直接對接公開金融 API，數據來源與計算方式說明如下：

---

## 一、 即時數據來源與對接通道

| 資料維度 | 來源渠道 | 提取欄位 / 說明 |
| :--- | :--- | :--- |
| **最新成交市價** | Yahoo Finance / TWSE 公開 API | `regularMarketPrice` / `chartPreviousClose` |
| **真實除息歷史** | Yahoo Finance Events API | 過去 12 個月內所有除息事件 (`events.dividends`) |
| **標的中文/英文全名** | 官方發行資料庫 | `longName` / `shortName` |
| **歷史價格波段** | 過去 1 年月收盤價序列 | `indicators.quote[0].close` |

## 二、 客觀指標計算邏輯 (無人為預設值)

### 1. 真實年化殖利率 (Actual Annualized Yield)
$$\text{Yield Rate} = \frac{\sum_{i=1}^k \text{Dividend Amount}_i}{\text{Latest Market Price}}$$
* 其中 $k$ 為過去 1 年內實際除息總次數。
* 絕不使用投信宣傳或單次配息年化暴力乘算，忠實呈現過去 12 個月每股實際落袋總現金股利與當前市價之真實比率。

### 2. 配息頻率與落袋月份推估
* **除息次數 $\ge 10$ 次**：自動判定為「月配息 (Monthly)」，落袋月份為 1~12 月全年度。
* **除息次數 $3 \sim 4$ 次**：自動判定為「季配息 (Quarterly)」，精確依據實際除息戳記之月份（如 2/5/8/11 或 3/6/9/12）填入 1~12 月現金流矩陣。
* **除息次數 $1 \sim 2$ 次**：判定為「半年配 / 年配」。
* **除息次數 $= 0$ 次**：判定為「累積成長型（如 00757，殖利率為 0.0%）」。

### 3. 過去 1 年最大回撤 (1-Year Historical MDD)
$$\text{MDD} = \frac{\min(Close) - \max(Close)}{\max(Close)}$$
直接取過去 12 個月各月收盤價中之最高點與隨後最低點計算最大跌幅。
