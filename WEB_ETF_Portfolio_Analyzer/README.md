# ETF 智能投資組合與獲利風險動態評估系統 (ETF Portfolio Studio)

一套專為台灣投資人設計的 **全市場即時連網 ETF 資產配置、現金流試算與多維度極端壓力測試** 互動式分析系統。

> **數據誠實宣告 (Data Integrity Guarantee)**：  
> 本系統全面對接 **Yahoo Finance / 證交所公開金融 API**，成交價格、除息歷史紀錄均為真實實體行情。年化殖利率由「近 12 個月實際配息總額 $\div$ 最新收盤價」客觀即時計算，**拒絕任何寫死假常數與行銷展示假數據**。

## 核心升級亮點

### 1. 全市場任意標的「線上即時抓取」（打破清單限制）
* **不限制任何預設標的**：在介面中點擊「＋ 線上搜尋 / 加入其他 ETF」，輸入**任意台股或美股 ETF 代號**（如 `00915`, `00757`, `00935`, `006208`, `VOO`, `QQQ`, `JEPI`）。
* **即時連線獲取真實數據**：
  1. **最新收盤價**（例如：00940 最新市價 NT$ 13.27、00919 最新市價 NT$ 31.65）。
  2. **近 12 個月真實除息清單**（每一期的金額與確切發放月份）。
  3. **動態計算實測殖利率**：$\text{殖利率} = \frac{\sum \text{近一年實收股利}}{\text{最新收盤市價}}$。
  4. **真實配息頻率判定**：根據除息次數自動歸類為月配、季配（精確辨識哪幾個月領息）或半年配。

### 2. 即時現金流落袋矩陣（1~12 月月曆）
* 根據各檔 ETF 過去 1 年「真實除息月份」，精確計算 1~12 月每個月實際進帳金額。
* 計算變異係數 (CV)，客觀診斷現金流平穩程度。

### 3. 極端壓力測試（MDD 實證模擬）
* 依據標的過去 1 年真實收盤價格序列計算波動度與回撤幅度，推估在升息或疫情衝擊下的下檔防護能力。

### 4. 當日實務下單張數換算（1 張 = 1,000 股）
* 即時將配置本金換算為當日可買進張數，清楚呈現「XX 張 + XX 股」實務零股下單拆解。
* 提供「整張下單對齊」功能，一鍵將標的金額取整至整數張數。

### 5. 自訂組合管理與防未儲存切換機制 (Portfolio Strategy Manager)
* **自訂組合隨意儲存**：可將任何調整過權重、新增標的之後的組合「另存為新方案」，名稱預設自動帶入股票代號排列（例如 `00919 + 00940 + 00937B`）亦可自由輸入。
* **分區切換選單**：下拉選單自動分為「⭐ 我的自訂組合」與「🏛️ 官方經典範本」，支援自訂組合刪除與一鍵「↺ 重設本組合」還原初始權重。
* **未儲存切換防呆警告**：只要當前配置被更動，畫面即標示「● 未儲存」；若未儲存就切換其他組合，系統會自動跳出警告彈窗，詢問是否「先儲存並切換」或「放棄變更直接切換」，杜絕誤觸遺失心血。
