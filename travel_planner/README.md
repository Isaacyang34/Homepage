## 🗺️ 網頁核心特色功能

### 1. 晴雨雙備案一鍵切換 (`☀️ 好天氣線` vs `🌧️ 下雨天線`)
第一天在抵達新竹橫山**「合興車站 / 合興豬腳飯」**時，系統設計了天氣分支決策：
- **☀️ 晴天線（分支二）**：
  內灣老街 ➔ 中油尖石站（加滿油） ➔ 宇老觀景台（海拔 1,450m 俯瞰玉峰山谷） ➔ 巴陵加油站 ➔ 明池森林遊樂區（北橫明珠） ➔ 中油大同站 ➔ 羅東奕順軒 ➔ 猿燒日料晚餐（17:30 預約） ➔ 礁溪民宿。
- **🌧️ 雨天線（分支一）**：
  關西新昀加油站 ➔ 大溪老街（巴洛克騎樓遮雨品嚐老阿伯豆干） ➔ 新店碧潭水岸 ➔ 坪林中油站（北宜公路中繼點喝包種茶） ➔ 礁溪民宿（先 Check-in 換下雨具泡湯） ➔ 羅東奕順軒 ➔ 猿燒日料晚餐。

### 2. 真實路徑貼合（OSRM Real-Road Polylines）
地圖路徑並非簡單的直線連線，而是透過真實路網計算出精準的行車軌跡（包含台7線北橫、台9線北宜公路、台2線濱海公路、台3線等），長達數千個高精度座標點，山道轉角清晰可見。

### 3. 地圖與時間軸雙向連動
- 點選右側時間軸的任一張站點卡片，地圖將平滑飛行（FlyTo）至該站點並自動彈出氣泡窗。
- 每個站點皆提供 **「🚗 開啟 Google 導航」** 快捷鍵，手機點擊可直接呼叫 Google 地圖 App 進行導航。

### 4. 四大多功能資訊面板
- **📋 行程規劃**：分天篩選（全部 / DAY 1 / DAY 2 / DAY 3）、出發時間、行車里程、停留時間、已抵達打卡勾選框。
- **🌦️ 即時山區天氣**：串接 Open-Meteo API，提供卓蘭、宇老（1450m 高山溫差）、礁溪、三貂角（海風風速）、基隆、富貴角、北投等地的即時溫度與降雨預報。
- **🎒 騎士裝備檢核表**：胎壓、煞車皮、兩件式雨衣、防摔手套、行車記錄器、住宿與餐廳預約確認清單（勾選狀態會自動儲存於瀏覽器 LocalStorage）。
- **🍜 沿線美食與伴手禮地圖**：永安喜餅、奕順軒奶凍捲、猿燒季節料理、基隆廟口夜市、百年李鵠餅店、淡水阿給夕陽、新竹海瑞摃丸。

## 💡 騎士重要注意事項

- **北橫進山前加油提醒**：走好天氣路線進入尖石、北橫高山前，**務必在中油尖石站將油箱加滿**！後續至巴陵前山路補給少、坡度大，保持充足油量是山道安全第一要件。
- **宇老觀景台高山溫差**：宇老海拔約 1,450 公尺，氣溫通常比平地低約 8～9°C，午後易起霧，請隨身備妥防風保暖外套與黃色/清晰鏡片。
- **晚餐與住宿預約**：
  - Day 1 晚餐：羅東【猿燒 季節料理】已預約 17:30。
  - Day 1 住宿：宜蘭礁溪溫泉民宿（三妹爌肉飯2F / Airbnb 預算約 1,837 元）。
  - Day 2 住宿：台北北投馥悅溫泉酒店（預算約 2,839 元）。
